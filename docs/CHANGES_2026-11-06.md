# Scatter comparison update — 2026-11-06

## What changed

- The scatter plots only funds in the Compare tray (maximum six). Unselected catalogue funds are used only to calculate a peer split and never become chart points.
- Peer split lookup first uses active funds in the selected sub-categories. If fewer than ten matched peers exist, it widens to the selected asset classes. The active scope and fallback are disclosed in the UI.
- With no adequate peer split, the engine falls back through selected median (3+ funds), selected mean (2+), then a finite custom split. One selected fund can use peer or custom thresholds.
- Both axes preserve natural numeric direction. Metric directions are declared in `config/metric-directions.json`, each with a short rationale. Green, amber, and red show favorable, mixed, and unfavorable corners; unknown direction leaves all corners neutral until the user chooses Higher or Lower.
- Fund names and split values are no longer stamped over the plot. Click or keyboard-activate a quadrant or split line to reveal its label in a dedicated callout below the plot; the active callout temporarily clears point labels. Compact axis titles use units shown on ticks and remain readable on narrow screens. Split positions are editable by dragging or entering formatted values. Scatter preferences migrate by dropping removed scope, outlier, zoom, and orientation settings.
- PNG export now inlines chart styles and includes a selected-fund legend with plotted values, quadrant, and data date. CSV and sortable table ranks remain local to the selected sample.

## Decisions

- Peer splits require ten funds with both metrics so a handful of peers cannot set the reference. The asset-class widening is disclosed because it is less specific than a sub-category.
- All peer and selected split calculations are performed from exact finite values; missing metrics are omitted and listed with their reason. No value is filled or estimated.
- Metric direction is configuration-backed. `max_drawdown` is higher-is-better because its values are stored as negative drawdown returns (closer to zero is better); `var_95` is lower-is-better because it is stored as a positive loss magnitude. Beta and R-squared default to no preference.
- Directional percentile and ordinal rank are calculated within the plotted selection; peer funds do not affect rank.

## Validation

- Unit coverage exercises selected-only plotting, one-fund peer classification, peer-scope fallback, split fallback order, directional quadrants, registry direction coverage, and custom split parsing.
- The project check and unit suite were run locally. Browser E2E is not configured in this checkout (`@playwright/test` and a `test:e2e` script are absent), so no automated browser E2E result is claimed.
