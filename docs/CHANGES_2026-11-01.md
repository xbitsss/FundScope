# FundScope changes · 1 November 2026

This pass implements the one-shot history, filter and mobile repair against the live repository state at commit `da35e7a`.

## Diagnostic

- `pnpm diagnose:snapshot` now verifies manifest/index integrity and reports encrypted NAV sizes without pretending that encrypted fields can be decoded without `DATA_PASSPHRASE`.
- The checked live snapshot contained 14,200 funds and 14,200 history references; encrypted NAV p50/p95/max sizes were 2,951 / 25,784 / 49,614 bytes and total encrypted NAV size was 94.1 MiB. Detailed histograms and decrypted samples remain a deployment-secret-only diagnostic.

## Filters and saved screens

- Added a pure reducer-backed filter engine with explicit Open/Closed/Interval, Direct/Regular/Unknown and Growth/IDCW/Unknown facets.
- The default universe is Direct + Growth + Open. Empty selections mean no restriction; Unknown never passes a restrictive default unless selected explicitly.
- Facets count against every other active facet and keep zero-count choices disabled. Active filter count is per facet, not per selected category.
- Saved screens write version 2 structured arrays and still read the previous pipe-delimited/sentinel format.
- AMFI is the only sub-category source; MFapi category remains a reconciliation signal and cannot relabel the sub-category.

## History and ETL

- Browser history reads now return loaded/unavailable/failed results, perform one bounded retry, and cache successful series by snapshot ID.
- Same-snapshot catalog replacement preserves loaded history; a new snapshot ID clears stale browser history. Web history loads no longer recompute or overwrite ETL metrics.
- Added a migration-safe `nav_history` IndexedDB store and history status fields/queue ordering for ETL payloads.
- Added retry backoff (1h, 6h, 24h, 72h, then 7d), retryable failure ordering, quality-gate logging, twice-daily refresh scheduling and a pre-deploy encrypted-file integrity/size verifier.

## Mobile

- Added a bottom tab bar on phone widths, full-width filter sheet, card results below 640px, hidden page scrollbars and a mobile-safe full-screen drawer.
- Desktop retains the sticky, horizontally scrollable data table. Mobile drawer outside-click dismissal is disabled; close and Escape remain available.

## Verification

- `pnpm check` passes.
- `pnpm test` passes: 45 tests.
- `pnpm etl:bundle` passes.
- `pnpm build:web` requires the encrypted `dist/data/manifest.json` generated by the nightly ETL; no local secret or fabricated snapshot was added.
