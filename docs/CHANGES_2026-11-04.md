# FundScope changes · 4 November 2026

## Applied filters

- Added a shared `AppliedFilters` chip strip for the screener summary and mobile filter sheet, plus shared chips inside the multi-select filter cards.
- Chips wrap and use measured row fitting, including space for `+N more` and `Clear all`. Long text truncates within the chip while the complete value is available in its details panel.
- Added per-value removal, five-second Clear all undo, keyboard chip navigation/removal, mobile details sheet focus trapping, and live result-count announcements. Kept the live region mounted after the final filter is cleared.
- Added unit tests for chip formatting, unknown values, range formatting, row fitting, and trailing controls.

## Compare scatter

- Added a Compare → Scatter view with searchable numeric metric axes, metric groups and coverage, axis direction overrides, presets, scope selection, median/mean/peer-median/custom splits, and best-at-top-right orientation.
- Added a worker query that returns typed point/rank arrays, direction-aware quadrants, explicit not-plotted reason counts, outlier bounds, and per-axis paired coverage. Missing values are excluded without imputation.
- Added a canvas/SVG plot with pointer hit-testing, pan/zoom, pinch, draggable split lines, inspected-fund details, quadrant summaries/actions, a sortable virtualized table, and local CSV/PNG export.
- Persisted scatter preferences in local state and `localStorage`; new saved screens use version 3 and continue to load version 2 screens.
- Added unit coverage for quadrant directions/ties, thresholds, peer medians, missing data, presets, ranks, saved-screen migration, and a 14,200-fund query.

## Decisions and validation limits

- Peer median is defined as the median of the per-sub-category medians so each sub-category contributes one threshold observation, regardless of its size.
- A tied value belongs to the favorable side for a higher/lower direction. For no-preference axes, it belongs to the high-value side; any no-preference axis suppresses Best/Avoid labels.
- Table and chart show top-percentile ranks for higher/lower directions and empirical percentiles for no-preference directions. Missing metrics retain their reason code and do not receive a rank.
- `pnpm check` through Corepack is unavailable because the pinned pnpm package cannot be downloaded in this offline environment. The already-installed TypeScript, Vitest, and Vite binaries are used for local validation instead.
- The project's `check` script passed using the locally available pnpm 11.25.0 fallback: TypeScript project build, Vite production build, and 103 taxonomy inventory checks. The full Vitest suite passed all 210 tests across 26 files. Vite reports the existing Zod annotation and >500 kB main-chunk warnings.
- The repository has no Playwright dependency or `test:e2e` script, and package registry access is unavailable. Automated browser runs and the requested viewport screenshots were therefore not produced; no phone performance or frame-rate claim is made from the 14,200-row unit test.
